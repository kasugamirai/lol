# 星核峡谷 · Nexus Rift

浏览器里的 5v5 MOBA（类 LOL）。三维低多边形画面，联机对战通过 **Yjs 同步中继**，玩家身份与战绩数据使用 **Nostr**。

- 两张地图：**召唤师峡谷**（三路 + 野区 + 巨龙/男爵）与 **极地大乱斗**（单路，3 级起步）
- 8 名原创英雄，每人 QWER 四个技能（开局即全部学会，升级可提升技能等级），6 个召唤师技能、27 件装备（含合成路线）
- 小兵、防御塔（塔仇恨、护甲递增）、水晶枢纽、星核、野怪营地、巨龙与男爵增益、守卫与视野、草丛、战争迷雾
- 电脑 AI：对线、补刀、野区、支援、团战、推塔、控龙，人数不足时自动补位
- 快速匹配、房间列表、邀请链接、观战、断线托管与重连、主机迁移
- Nostr：打开网页自动创建密钥账户，也可导入 nsec 或用 NIP-07 浏览器扩展登录；战绩与排行榜存在 Nostr 中继上

## 操作

## 本地运行

```bash
npm install
npm run dev
```

测试多人联机可以在不同标签页使用不同身份：`http://localhost:5173/?id=alice`、`?id=bob`。

其他 URL 参数：

- `?room=<房间号>` 直接进入房间（邀请链接）
- `?practice=rift|aram&size=1..5&diff=0..2&champ=<英雄id>` 直接开始人机练习

## 部署（Cloudflare）

`wrangler.jsonc` 把 `dist/` 作为纯静态站点发布（单页应用回退），不需要 Vite 插件：

```bash
npm run deploy
```

连接 GitHub 仓库的 Cloudflare Workers Builds 会自动执行 `npm run build` 并用 `wrangler.jsonc` 部署。

## 架构

```
src/
  game/        纯逻辑（无 DOM）：地图、寻路、英雄/技能/装备数据、战斗、AI、视野、网络同步
  render/      three.js 渲染：地形、程序化模型、特效、战争迷雾、血条叠加层、小地图
  net/         Yjs 连接：大厅（房间广播 + 匹配）、房间文档
  nostr/       身份（密钥/NIP-07）与 Nostr 存储（资料、战绩、排行榜）
  ui/          菜单、房间/选英雄、游戏 HUD、商店、结算
```

### 联机同步（Yjs）

中继：`wss://ws.flow.plateau.reearth.io/<房间名>?token=netdisk`（y-websocket 协议）。

- **大厅房间** `nexusrift-lobby-v1`：只用 awareness。房主广播房间信息；匹配队列也放在 awareness 里，排队最早的客户端担任撮合者，凑齐玩家后创建房间并发出邀请。
- **对局房间** `nexusrift-room-v1-<id>`：
  - `Y.Doc`：房间设置、座位与选英雄、聊天、断线存档 —— 低频、需要持久化的数据。
  - `awareness`：每个客户端以 20Hz 广播自己英雄的快照和一个短时事件队列（施法、伤害、死亡……）；主机额外以 10Hz 广播世界快照（小兵、野怪、防御塔、电脑英雄）。每秒发一次完整快照，其余时间只发变化频繁的字段。awareness 不写入文档历史，所以高频同步不会让文档无限增长。
- **主机选举**：所有客户端按 (已同步, 加入时间, clientID) 排序得出同一个主机，由它模拟小兵、防御塔、野怪和电脑英雄。主机离开后其他客户端接管；玩家掉线 6 秒后由主机以 AI 托管，重连后从主机快照恢复。
- **权威划分**：每个客户端对自己的英雄负责（移动、冷却、生命值）。技能命中由施法者判定，然后把伤害事件发给目标的所有者结算；其他客户端只重放施法特效。远端单位按 130ms 延迟做快照插值。

### Nostr

- 首次打开时用 `nostr-tools` 生成密钥并保存在 localStorage；可在「Nostr 账户」页备份或导入私钥，或使用 NIP-07 扩展。
- 进入房间时用 kind 22242 事件签名证明身份，其他玩家在座位上看到 ✓。
- 战绩：每局结束发布一条 NIP-78（kind 30078）事件 `d=nexusrift:match:<id>`，并更新 `d=nexusrift:stats` 统计；排行榜按 `#t=nexusrift-stats` 聚合查询。
- 资料：修改名字时发布 kind 0。

## 开发工具

`scripts/` 下有无界面的模拟脚本（需要 [bun](https://bun.sh)），用于平衡性和回归测试：

```bash
bun scripts/sim.ts rift 40 5 1     # 地图 分钟 每队人数 随机种子：10 个 AI 对战
bun scripts/render-map.ts          # 把地图布局输出为 PNG
```
